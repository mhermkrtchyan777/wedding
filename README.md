# Հարսանյաց հրավեր / Wedding invitation site

Ստատիկ կայք՝ առանց build-ի և առանց Node.js-ի։ Բացվում է ուղիղ browser-ում։
Static site — no build step, no Node.js. Opens straight in a browser.

```
index.html              ← ամբողջ բովանդակությունը (տեքստ, ծրագիր, հասցեներ)
css/style.css           ← ձևավորումը
js/config.js            ← ⭐ կարգավորումներ՝ ամսաթիվ, Google Sheets-ի հասցե
js/main.js              ← տրամաբանությունը (հետհաշվարկ, քարտեզներ, ձևաթուղթ)
img/                    ← լուսանկարները
apps-script/Code.gs     ← Google Sheets-ի backend-ը
apps-script/SETUP.md    ← ⭐ Google Sheets-ի միացման ուղեցույց
```

---

## Արագ սկիզբ

### 1. Դիտել լոկալ

```bash
cd "wedding-invitation" && python3 -m http.server 8000
```

Ապա բացեք http://localhost:8000

> `index.html`-ը կարելի է նաև ուղիղ բացել browser-ում, բայց տեղական սերվերով
> ավելի ճիշտ է՝ ամեն ինչ աշխատում է ինչպես իրական կայքում։

### 2. Միացնել Google Sheets-ը

Հետևեք **[apps-script/SETUP.md](apps-script/SETUP.md)**-ին (~5 րոպե),
ապա տեղադրեք ստացված հասցեն `js/config.js`-ում․

```js
appsScriptUrl: 'https://script.google.com/macros/s/AKfyc.../exec',
```

Քանի դեռ այս դաշտը դատարկ է, ձևաթուղթը աշխատում է **փորձնական ռեժիմով**՝
տվյալները ցուցադրվում են browser-ի console-ում (F12), չեն պահվում։

## Ի՞նչ փոխել

### `js/config.js` — կարգավորումներ

| Դաշտ | Ինչի համար է |
|---|---|
| `weddingDate` | Հետհաշվարկի ամսաթիվը։ `+04:00` = Հայաստանի ժամանակ |
| `appsScriptUrl` | Google Sheets-ի հասցեն (տես SETUP.md) |
| `maxGuests` | Առավելագույն հյուրերի քանակը մեկ հայտում |
| `yandexDomain` | `yandex.com` կամ `yandex.ru` |

### `index.html` — բովանդակություն

Բոլոր փոփոխման ենթակա տեղերը նշված են այսպիսի մեկնաբանություններով․

```html
<!-- ============ ՓՈԽԵԼ / EDIT: անունները ============ -->
```

Փոխելու ենթակա են՝ անունները, ամսաթիվը, հրավերի տեքստը,
օրվա ծրագիրը և պատասխանի վերջնաժամկետը։

> ⚠️ Ամսաթիվը երկու տեղում է՝ `index.html`-ում (տեսանելի տեքստ) և
> `js/config.js`-ում (հետհաշվարկ)։ Փոխեք երկուսն էլ։

### Լուսանկարներ

Դրեք ձեր նկարները `img/` պանակում այս անուններով․

| Ֆայլ | Որտեղ | Խորհուրդ |
|---|---|---|
| `hero.jpg` | Գլխավոր էկրան | ուղղահայաց, min 1200×1500, < 500 KB |
| `story-1.jpg` | Հրավերի բաժին | 4:5 հարաբերություն, < 300 KB |
| `story-2.jpg` | Հրավերի բաժին | 4:5 հարաբերություն, < 300 KB |

Ապա փոխեք ընդլայնումը `.svg` → `.jpg` երկու տեղում․

- `css/style.css` → `.hero__media` → `url("../img/hero.jpg")`
- `index.html` → `<img src="img/story-1.jpg" …>` և `story-2.jpg`

> 💡 **Կարևոր՝** սեղմեք նկարները մինչև տեղադրելը (https://squoosh.app)։
> Հյուրերի մեծ մասը կբացի հեռախոսով, հաճախ՝ մոբայլ ինտերնետով։

### Քարտեզներ

Ամեն կետ ունի կոորդինատներ `index.html`-ում․

```html
<li class="tl reveal" data-lat="40.184900" data-lng="44.513600">
```

**Կոորդինատները վերցնելու համար՝** Google Maps → աջ սեղմում վայրի վրա →
վերևի տողում կհայտնվեն թվերը → սեղմեք՝ պատճենելու համար։

Կոճակները ստեղծվում են ավտոմատ։ Հեռախոսի վրա բացվում է
համապատասխան հավելվածը, համակարգչի վրա՝ վեբ-տարբերակը։

**Կետ ավելացնելու համար** պատճենեք ամբողջ `<li class="tl reveal" …>` բլոկը։

## Հրապարակում — GitHub Pages

Կայքն ամբողջությամբ ստատիկ է, ուստի GitHub Pages-ը լիովին բավարար է և անվճար։

### 1. Ստեղծեք repo

Բացեք https://github.com/new → անվանեք, օրինակ՝ `wedding` → **Public** →
**առանց** README/`.gitignore` → **Create repository**

### 2. Ուղարկեք ֆայլերը

`wedding-invitation` պանակի ներսում․

```bash
git init && git add -A && git commit -m "Wedding invitation site"
```

```bash
git branch -M main && git remote add origin https://github.com/ՁԵՐ-ՕԳՏԱՆՈՒՆԸ/wedding.git && git push -u origin main
```

### 3. Միացրեք Pages-ը

Repo → **Settings** → **Pages** →
**Source: Deploy from a branch** → **Branch: `main` / `(root)`** → **Save**

1–2 րոպեից կայքը հասանելի կլինի․

```
https://ՁԵՐ-ՕԳՏԱՆՈՒՆԸ.github.io/wedding/
```

### 4. Փոփոխություններից հետո

```bash
git add -A && git commit -m "Update details" && git push
```

## Տեխնիկական մանրամասներ

- **Առանց կախվածությունների** — միայն Google Fonts (CDN)։ Ոչ մի framework։
- **Հասանելիություն** — ստեղնաշարով նավիգացիա, `prefers-reduced-motion`,
  16px input-ներ (iOS-ը չի մեծացնում էկրանը)։
- **CORS** — ձևաթուղթն ուղարկում է JSON՝ `text/plain` վերնագրով, որպեսզի
  browser-ը բաց թողնի preflight հարցումը, որին Apps Script-ը չի պատասխանում։
  Եթե պատասխանը կարդալ չհաջողվի, կրկնվում է `no-cors` ռեժիմով։
- **Անվտանգություն** — Apps Script-ի հասցեն հրապարակային է, բայց միայն
  գրում է նոր տողեր։ Աղյուսակի պարունակությունը հասանելի չէ դրսից։
