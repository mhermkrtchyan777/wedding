# Google Sheets-ի միացում / Connecting Google Sheets

Այս քայլերը կատարվում են **մեկ անգամ**, տևում են ~5 րոպե։
One-time setup, about 5 minutes.

---

## 1. Ստեղծեք աղյուսակը

1. Բացեք https://sheets.new
2. Անվանեք այն, օրինակ՝ **Հարսանիք — RSVP**

## 2. Բացեք Apps Script-ը

Աղյուսակում՝ **Extensions → Apps Script**
(հայերեն ինտերֆեյսում՝ **Ընդլայնումներ → Apps Script**)

## 3. Տեղադրեք կոդը

1. Ջնջեք խմբագրիչում եղած ամեն ինչ (`function myFunction() {}`)
2. Պատճենեք **[Code.gs](Code.gs)** ֆայլի **ամբողջ** պարունակությունը
3. Տեղադրեք խմբագրիչում
4. Պահպանեք՝ **Ctrl/Cmd + S**

## 4. Հրապարակեք որպես Web App

1. Վերևի աջ անկյունում՝ **Deploy → New deployment**
2. **Select type** (ատամնանիվի պատկերակը) → **Web app**
3. Լրացրեք․

   | Դաշտ | Արժեք |
   |---|---|
   | Description | `RSVP` |
   | Execute as | **Me** (ձեր հաշիվը) |
   | Who has access | **Anyone** |

   > ⚠️ **Who has access = Anyone** պարտադիր է։
   > «Anyone with Google account» տարբերակի դեպքում հյուրերը չեն կարողանա ուղարկել։
   > Սա չի բացում ձեր աղյուսակը հանրությանը — միայն թույլ է տալիս գրել նոր տողեր։

4. **Deploy**
5. Google-ը կխնդրի թույլտվություն․
   **Authorize access** → ընտրեք ձեր հաշիվը →
   **Advanced** → **Go to … (unsafe)** → **Allow**

   > «Unsafe» զգուշացումը նորմալ է — դա ձեր սեփական, չհրապարակված սկրիպտն է։

6. Պատճենեք **Web app URL**-ը։ Այն ունի այս տեսքը․

   ```
   https://script.google.com/macros/s/AKfycbx.../exec
   ```

## 5. Տեղադրեք հասցեն կայքում

Բացեք **`js/config.js`** և տեղադրեք հասցեն․

```js
appsScriptUrl: 'https://script.google.com/macros/s/AKfycbx.../exec',
```

## 6. Ստուգեք

**ա) Backend-ը** — բացեք Web App URL-ը browser-ում։ Պետք է տեսնեք․

```json
{"result":"success","status":"ok","coming":0,"notComing":0,"submissions":0}
```

**բ) Ամբողջ շղթան** — բացեք կայքը, լրացրեք ձևաթուղթը փորձնական անունով,
ուղարկեք, և ստուգեք աղյուսակը։ Պետք է հայտնվեն երկու թերթ․

- **RSVP** — մեկ տող յուրաքանչյուր հյուրի համար
- **Ամփոփում** — ընդհանուր թվերը

Ջնջեք փորձնական տողերը, երբ համոզվեք որ աշխատում է։

## Աղյուսակի սյուները

| Սյուն | Բովանդակություն |
|---|---|
| **Ամսաթիվ** | Երբ է ուղարկվել |
| **Անուն** | Հյուրի անունը |
| **Ազգանուն** | Հյուրի ազգանունը |
| **Պատասխան** | `Կգա` կամ `Չի գա` |
| **Հայտի ID** | Միևնույն ընտանիքի/հայտի հյուրերն ունեն նույն ID |
| **Հյուրերի քանակ** | Քանի հոգի էին այդ հայտում |

Յուրաքանչյուր հյուր՝ առանձին տող։ Այսպես ընդհանուր թիվը հաշվելը պարզ է․
զտեք `Պատասխան = Կգա` և նայեք տողերի քանակին։

---

## Ծանուցում նոր պատասխանների մասին (ըստ ցանկության)

Աղյուսակում՝ **Tools → Notification settings → Edit notifications**
→ **Any changes are made** → **Email – right away**

Այսպես ամեն նոր պատասխանի դեպքում կստանաք նամակ։

---

## Կոդը փոխելուց հետո

Եթե խմբագրեք `Code.gs`-ը, **պարտադիր** նորից հրապարակեք․

**Deploy → Manage deployments → ✏️ (edit) → Version: New version → Deploy**

URL-ը **չի փոխվում**։ Եթե փոխարենը սեղմեք *New deployment*, կստանաք նոր URL
և ստիպված կլինեք թարմացնել `js/config.js`-ը։

## Խնդիրների լուծում

| Խնդիր | Պատճառ / լուծում |
|---|---|
| Ձևաթուղթը սխալ է տալիս | Ստուգեք որ `appsScriptUrl`-ը վերջանում է `/exec`-ով, ոչ թե `/dev`-ով |
| Տողերը չեն ավելանում | *Who has access* = **Anyone**, ոչ թե «Anyone with Google account» |
| `{"result":"error"…}` | Apps Script-ում՝ **Executions** բաժնում կտեսնեք սխալի մանրամասները |
| Ոչինչ չի պատահում | Բացեք browser-ի console-ը (F12) և նայեք `[wedding]` սկսվող հաղորդագրությունները |
| Անունները խզբզոց են | Աղյուսակում՝ **File → Settings → Locale**, ապա նորից բացեք |
